Examples Documentation

This section contains executable examples with their actual outputs captured from CI.

About This System

Examples-as-Tests-as-Docs Pipeline

This documentation uses a hard 1:1 mapping system where:

  • Every example is an executable Python script in examples/docs/

  • CI runs each example and captures its output to examples/docs_outputs/

  • The exact output shown here is what CI captured - no hand-written outputs

  • If code changes cause output to diverge, CI fails and blocks the merge

How It Works

  1. Developer writes a Python example in examples/docs/

  2. Run python scripts/generate_docs_outputs.py to capture outputs

  3. Reference the output in RST using .. literalinclude::

  4. CI validates that outputs match and fails on divergence

Adding New Examples

To add a new example:

# 1. Create example script
vim examples/docs/03_my_example.py

# 2. Generate outputs
python scripts/generate_docs_outputs.py

# 3. Reference in RST
.. literalinclude:: ../examples/docs_outputs/03_my_example.txt
   :language: none

# 4. Commit both code and outputs
git add examples/docs/03_my_example.py examples/docs_outputs/
git commit -m "Add example: my_example"

Testing

The system includes automated tests:

# Run all example tests
pytest tests/test_docs_examples.py -v

# Validate outputs
python scripts/validate_docs_outputs.py

Community Detection Example

This example demonstrates running Louvain community detection on a multilayer network.

Source code:

 1#!/usr/bin/env python
 2"""
 3Example: Community Detection
 4==============================
 5
 6This example demonstrates running community detection on a multilayer network
 7and examining the results.
 8"""
 9
10import sys
11from pathlib import Path
12
13# Add parent directory to path for imports
14sys.path.insert(0, str(Path(__file__).parent.parent.parent))
15
16from py3plex.core import multinet
17from py3plex.algorithms.community_detection import multilayer_louvain
18
19
20def main():
21    """Run community detection example."""
22    print("Example: Community Detection on Multilayer Network")
23    print("=" * 60)
24    
25    # Create a small test network with clear community structure
26    print("\n1. Creating network with community structure...")
27    net = multinet.multi_layer_network(directed=False)
28    
29    # Add two communities in layer 1
30    edges_layer1 = [
31        ('A', 'B', 'social', 'social'),
32        ('B', 'C', 'social', 'social'),
33        ('C', 'A', 'social', 'social'),  # Community 1
34        ('D', 'E', 'social', 'social'),
35        ('E', 'F', 'social', 'social'),
36        ('F', 'D', 'social', 'social'),  # Community 2
37    ]
38    
39    # Add edges
40    for src, dst, src_layer, dst_layer in edges_layer1:
41        net.add_edges([{
42            'source': src,
43            'target': dst,
44            'source_type': src_layer,
45            'target_type': dst_layer
46        }])
47    
48    # Add sparse connection between communities
49    net.add_edges([{
50        'source': 'C',
51        'target': 'D',
52        'source_type': 'social',
53        'target_type': 'social'
54    }])
55    
56    print(f"   Added {len(list(net.get_nodes()))} nodes")
57    print(f"   Added {len(list(net.get_edges()))} edges")
58    
59    # Run community detection
60    print("\n2. Running Louvain community detection...")
61    partition, _ = multilayer_louvain(net, random_state=42)
62    
63    # Analyze results
64    print("\n3. Community assignments:")
65    print("-" * 60)
66    
67    # Group nodes by community
68    communities = {}
69    for node, comm_id in partition.items():
70        if comm_id not in communities:
71            communities[comm_id] = []
72        communities[comm_id].append(node)
73    
74    print(f"   Found {len(communities)} communities\n")
75    
76    for comm_id in sorted(communities.keys()):
77        nodes = sorted(communities[comm_id])
78        print(f"   Community {comm_id}: {', '.join(str(n) for n in nodes)}")
79    
80    # Calculate basic statistics
81    print("\n4. Community statistics:")
82    print("-" * 60)
83    sizes = [len(nodes) for nodes in communities.values()]
84    print(f"   Average community size: {sum(sizes) / len(sizes):.1f}")
85    print(f"   Largest community: {max(sizes)} nodes")
86    print(f"   Smallest community: {min(sizes)} nodes")
87    
88    print("\n✓ Community detection complete!")
89
90
91if __name__ == "__main__":
92    main()

Output:
