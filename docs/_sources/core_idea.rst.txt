Core Principles
===============

**py3plex** provides **simple**, **off-the-shelf** functionality for **multilayer** and **multiplex** network analysis.

Key Features
------------

1. **Simple API** - **Modular interface** for multilayer networks
2. **Advanced Visualization** - **State-of-the-art** multilayer network rendering
3. **NetworkX Compatible** - Built on top of **NetworkX** for seamless integration
