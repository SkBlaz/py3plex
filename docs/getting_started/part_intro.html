Getting Started: Your Journey Begins

“The beginning is the most important part of the work.” — Plato

Why Start Here?

You’ve decided to explore multilayer networks. Perhaps you’re a biologist trying to understand how proteins interact through multiple mechanisms. Perhaps you’re a social scientist studying how people connect across different platforms. Perhaps you’re an engineer modeling transportation systems that span multiple modes. Whatever brought you here, you’ve recognized that real-world systems are rarely simple—they have structure, layers, and complexity that matter.

This section is designed to get you from zero to productive as quickly as possible. We believe that the best way to learn is by doing, so we’ve structured these guides as hands-on experiences rather than passive reading.

What You’ll Find Here

The 5-Minute Quickstart is exactly what it sounds like: a rapid introduction that gets you to your first visualization and analysis in minutes. You’ll create a network, compute some statistics, and see results. This is ideal if you want to understand what py3plex can do before committing more time.

The 10-Minute Tutorial is a deeper dive. It tells a story—you’re a data scientist analyzing a multi-platform social network—and walks you through a complete analysis workflow. By the end, you’ll understand the core mental model of multilayer networks and have working code for common tasks.

The Installation Guide covers the practical details: how to install py3plex, which optional dependencies you might want, and how to verify your installation is working.

Common Issues addresses the problems you might encounter. We’ve collected the most frequent questions and provided clear solutions.

A Note on Learning

Network analysis is a skill that develops with practice. The concepts in this section will make more sense after you’ve used them a few times. Don’t worry if something seems abstract at first—return to these guides after working through some examples, and you’ll find new layers of understanding.

If you’re completely new to network analysis, we recommend reading through the conceptual material in Part II after completing these quickstart guides. Understanding why multilayer networks matter will help you make better modeling decisions in your own work.

Let’s Begin

Ready? Start with Chapter 1: Your First Five Minutes for a rapid introduction, or dive into Chapter 2: The Complete Workflow in Ten Minutes for a complete workflow.

Note

Learning Path Recommendation:

  • New to py3plex? → Start with the 5-Minute Quickstart

  • New to multilayer networks? → Read the 10-Minute Tutorial, then Part II (Concepts)

  • Experienced with networks, new to py3plex? → Skim the 5-Minute Quickstart, then jump to Part III (User Guide)
