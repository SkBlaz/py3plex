HOW IT WORKS
================================================================================

DEVELOPER WORKFLOW:
-------------------
1. Write Python example in examples/docs/
2. Run: python scripts/generate_docs_outputs.py
3. Outputs auto-captured to examples/docs_outputs/
4. Reference in RST: .. literalinclude:: ../examples/docs_outputs/filename.txt
5. Validate: python scripts/validate_docs_outputs.py
6. Commit both code and outputs
7. Push to GitHub

CI WORKFLOW:
------------
1. Trigger on push/PR
2. Run all examples: python scripts/generate_docs_outputs.py
3. Check for differences: git diff --exit-code examples/docs_outputs/
4. If differences found → FAIL (outputs diverged)
5. Validate RST references: python scripts/validate_docs_outputs.py
6. If validation fails → FAIL (missing references)
7. If everything matches → PASS (allow merge)

1:1 MAPPING:
------------
Each example.py → example.txt → referenced in RST
                  ↓
             CI validates
                  ↓
          Pass ✓ or Fail ✗
