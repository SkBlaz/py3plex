# DSL Query Zoo

A curated gallery of multilayer network analysis queries using the py3plex DSL.

## Overview

The Query Zoo demonstrates the expressiveness and power of the py3plex DSL through
7 comprehensive examples covering common multilayer analysis tasks:

1. **Basic Multilayer Exploration** — Layer statistics and structure
2. **Cross-Layer Hubs** — Nodes important across multiple layers
3. **Layer Similarity** — Structural alignment between layers
4. **Community Structure** — Multilayer community detection and analysis
5. **Multiplex PageRank** — Multilayer-aware centrality computation
6. **Robustness Analysis** — Network resilience to layer failures
7. **Advanced Centrality Comparison** — Versatile vs specialized hubs

Each query:
- Solves a real multilayer analysis problem
- Uses idiomatic DSL patterns
- Produces reproducible outputs
- Is fully tested (40 passing tests)

## Quick Start

### Run a Single Query

```python
from examples.dsl_query_zoo.datasets import create_social_work_network
from examples.dsl_query_zoo.queries import query_basic_exploration

# Load dataset
network = create_social_work_network(seed=42)

# Run query
result = query_basic_exploration(network)
print(result)
```

### Run All Queries

```bash
cd examples/dsl_query_zoo
python run_all.py
```

Output will be saved to `outputs/` directory:
- CSV files with query results
- PNG plots for visualization

### Run Tests

```bash
pytest tests/test_dsl_query_zoo.py -v
```

## Files

- **`datasets.py`** — Reproducible multilayer network generators
  - `create_social_work_network()` — 12 people across social/work/family layers
  - `create_communication_network()` — 10 people across email/chat/phone layers
  - `create_transport_network()` — 8 locations across bus/metro/walking layers

- **`queries.py`** — 7 example query functions with full documentation

- **`run_all.py`** — Script to execute all queries and generate outputs

## Extending the Query Zoo

To add a new query:

1. **Add query function** to `queries.py`:
   ```python
   def query_my_analysis(network):
       """Your query description.
       
       Args:
           network: A multi_layer_network instance
           
       Returns:
           pd.DataFrame with results
       """
       # Your DSL query here
       result = (
           Q.nodes()
            .from_layers(L["*"])
            .compute("degree")
            .execute(network)
       )
       return result.to_pandas()
   ```

2. **Add tests** to `tests/test_dsl_query_zoo.py`:
   ```python
   def test_my_analysis(social_work_network):
       result = query_my_analysis(social_work_network)
       assert isinstance(result, pd.DataFrame)
       # Add more assertions
   ```

3. **Update documentation** in `docfiles/how-to/query_zoo.rst`:
   - Add a new section with literalinclude
   - Explain the query and show example output
   - Include visualizations if applicable

4. **Update `run_all.py`** to include your query in the execution pipeline

## Design Principles

The Query Zoo follows these principles:

- **Reproducibility**: All datasets use fixed random seeds
- **Speed**: Queries run in seconds, suitable for CI
- **Clarity**: Code is self-documenting with comprehensive docstrings
- **Realism**: Examples solve actual multilayer analysis problems
- **Testability**: Every query has comprehensive tests
