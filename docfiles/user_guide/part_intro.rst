User Guide
==========

How-to guides for every major py3plex capability.

Chapters
--------

* **Working with Networks** — Create, load, query, and extract subnetworks
* **Statistics** — Layer density, node activity, edge overlap, versatility metrics
* **Community Detection** — Louvain, Infomap, multilayer modularity
* **Random Walks & Embeddings** — Node2Vec, DeepWalk for ML features
* **I/O and Formats** — Import/export in multiple formats
* **Visualization** — Publication-ready multilayer plots
* **DSL** — SQL-like query language for interactive exploration
* **Graph Operations** — Chainable API for transformations
* **Recipes & Workflows** — Ready-to-use solutions for common tasks
* **Case Studies** — Complete analyses from start to finish
