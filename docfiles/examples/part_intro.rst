Examples
========

Working code examples demonstrating py3plex capabilities.

Contents
--------

* **Network creation and loading** — Multiple ways to get data into py3plex
* **Statistical analysis** — Computing and interpreting multilayer metrics
* **Community detection** — Finding structure in your networks
* **Visualization** — Creating publication-ready figures
* **Random walks and embeddings** — Feature extraction for machine learning
* **Complete workflows** — End-to-end analyses combining multiple techniques

Organization
------------

* **Beginner** — Core concepts with small, simple networks
* **Intermediate** — Realistic scenarios with larger networks
* **Advanced** — Performance optimization and custom extensions

Browse the :doc:`index` to find examples relevant to your interests.

.. note::

   All examples assume py3plex is installed. Some require optional dependencies—check imports at the top of each example.
