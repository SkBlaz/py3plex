Py3plex GUI
===========

Web-based graphical interface for interactive network exploration.

.. warning::

   **Development Status:** The GUI is experimental, intended for local exploration and developer use. For production workflows, use the Python API.

--------

* **GUI Deployment** — Run locally or deploy on a server
* **GUI API Reference** — Backend API for developers
* **GUI Architecture** — Technical details for contributors
* **GUI Testing** — Testing infrastructure
