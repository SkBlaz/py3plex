Developer & Contributor Docs
============================

Development setup, architecture, and contribution guidelines.

Contents
--------

* **Development Guide** — Set up your environment, run tests, submit changes
* **Code Architecture** — Internal organization and design patterns
* **Repository Layout** — Map of the codebase
* **Contributing Guidelines** — Process for reporting bugs and proposing features

Getting Started
---------------

1. Read :doc:`development_guide` to set up your environment
2. Browse GitHub issues for items labeled "good first issue"
3. Start with something small—a documentation fix or a simple bug

.. tip::

   **Quick Paths:**

   * **"I want to make my first contribution"** → :doc:`development_guide` → find a "good first issue"
   * **"I want to add a new algorithm"** → :doc:`code_architecture` → :doc:`contributing`
   * **"I'm lost in the codebase"** → :doc:`repo_layout`
